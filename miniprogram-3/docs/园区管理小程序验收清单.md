# 园区管理小程序验收清单

本文档用于园区管理小程序阶段验收。当前小程序以本地 mock 数据完成页面和交互原型，后续接入 PC 端后端接口后，应按同一清单补充接口、权限、数据一致性和异常场景验收。

## 1. 验收范围

- 企业客户侧：首页、我要看房、物业服务、企业服务/增值服务、用户中心、我的工单。
- 管理员侧：通知中心、物业工单处理、增值服务工单处理、园区概览、租客详情。
- 公共能力：页面跳转、底部导航、表单校验、状态展示、mock 数据展示、接口接入预留。

## 2. 验收环境

- 微信开发者工具可正常打开项目。
- 小程序基础库版本满足项目配置要求。
- `miniprogram/app.json` 中页面路径配置完整。
- TypeScript 校验通过：

```bash
npx tsc --noEmit
```

## 3. 通用验收项

### 3.1 页面与导航

- [ ] 首页可正常打开，无白屏、报错、资源丢失。
- [ ] 底部导航可在首页、服务、通行码、发现/园区概览、我的之间切换。
- [ ] 自定义顶部导航返回按钮可正常返回上一页。
- [ ] 所有首页快捷入口可点击，并进入对应业务页面或合理的操作菜单。
- [ ] 所有新增页面均已在 `miniprogram/app.json` 注册。
- [ ] 页面在 iPhone 常见尺寸下内容不被顶部状态栏、底部安全区、底部导航遮挡。
- [ ] 长列表页面支持上下滚动，底部内容可完整查看。
- [ ] 文案、按钮、状态标签不重叠、不溢出、不异常换行。
- [ ] 页面整体风格与当前蓝色主视觉一致。
- [ ] 页面字体不使用明显加粗效果，保证视觉清晰。

### 3.2 数据与状态

- [ ] 当前 mock 数据可正常渲染。
- [ ] 空数据状态后续有设计或预留处理方案。
- [ ] 待受理、处理中、沟通中、已完成、待缴、已缴等状态展示颜色清晰。
- [ ] 不同业务状态对应的入口、按钮和提示语符合业务语义。
- [ ] 表单提交成功后有明确反馈。
- [ ] 必填项未填写时有提示，不允许无效提交。

### 3.3 异常与兼容

- [ ] 图片加载失败时页面不崩溃。
- [ ] 后续接口异常时应展示错误提示或空状态。
- [ ] 后续接口 loading 状态不影响页面操作。
- [ ] 手机号、金额、面积、时间等输入字段格式应有基础校验。
- [ ] 页面快速连续点击时不应重复提交。

## 13. 权限验收

### 13.1 企业客户权限

- [ ] 企业客户只能查看所属企业信息。
- [ ] 企业客户只能查看所属房间、合同、账单、工单。
- [ ] 企业普通成员不可修改企业关键资料。
- [ ] 企业管理员可维护企业资料。
- [ ] 未登录用户访问企业数据时应跳转登录或授权。

### 13.2 管理员权限

- [ ] 非管理员不能进入通知中心的管理员处理能力。
- [ ] 非管理员不能执行受理、派单、驳回、完成等动作。
- [ ] 管理员可按园区、楼宇、服务类型、工单状态查看数据。
- [ ] 管理员处理动作应记录操作人、操作时间和处理说明。

### 13.3 敏感数据

- [ ] 合同、账单、企业证照等敏感信息按角色控制可见字段。
- [ ] 手机号、联系人等个人信息不应在无权限页面暴露。
- [ ] 后续接口请求应携带登录态和 token。
