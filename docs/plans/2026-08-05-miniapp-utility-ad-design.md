# 小程序水电缴纳与广告推送设计方案

> 生成时间：2026-08-05
> 状态：已确认

## 背景与目标

园区小程序首页快捷入口目前为四列布局，仅展示看房、物业服务、增值服务、我的工单、入驻申请和停车缴费，第二行存在两个空位。本次新增“水电缴纳”和“广告推送”，形成完整八宫格，并复用现有 BladeX 水电抄表、合同账单、广告管理和小程序首页能力。

后台仅供园区管理员登录，入驻企业不能登录后台。企业成员通过小程序使用企业服务；企业管理员负责提交付款凭证和广告，园区管理员在后台审核留痕。广告不接入 Flowable，水电费不接入微信支付。

## 方案选型

### 水电缴纳

采用“线下付款凭证确认”方案：园区管理员根据抄表记录生成并确认账单，企业管理员在小程序上传付款凭证，园区管理员在后台确认到账或驳回。首版不需要微信支付商户号、APIv3 密钥和证书。

### 广告推送

复用后台现有“企业服务—广告管理”，不启动 Flowable。企业管理员在小程序提交广告，后台广告管理完成审核、驳回、上架和下架，所有动作写入业务审核日志。审核通过且处于有效展示期的上架广告自动出现在小程序首页。

## 角色与权限

- 企业普通成员：查看本企业水电账单、付款凭证状态和广告状态。
- 企业管理员：拥有普通成员权限，并可上传水电付款凭证、新建和提交广告、处理驳回后的重新提交。
- 园区管理员：仅通过后台生成和发布水电账单、审核付款凭证、审核及管理广告。
- 所有企业侧接口从小程序服务端成员关系取得 `tenantId + parkId + customerId`，禁止客户端指定企业范围。

## 水电缴纳设计

### 数据模型

复用：

- `biz_room_utility_record`：水表、电表抄表记录。
- `biz_contract_payment`：企业应收账单，水费使用 `fee_type=water`，电费使用 `fee_type=electric`。
- `biz_contract_payment_record`：园区管理员确认到账后的逐笔收款记录。

新增 `biz_utility_bill_detail`：

- 关联 `payment_id`、合同、企业、园区、房间和表计。
- 保存起止抄表记录、起止读数、实际用量、单价、金额和账期。
- 保存草稿、已确认、已发布状态及生成、确认、发布时间和操作人。
- 同一房间、表计、起止记录只能生成一条有效明细，防止重复计费。

新增 `biz_mini_payment_submission`：

- 保存账单、企业、提交成员、申报金额、凭证名称和地址。
- 状态为待确认、已确认或已驳回。
- 保存提交时间、审核人、审核时间和审核意见。
- 每次重新提交生成新记录，不覆盖历史凭证。

### 业务流程

1. 园区管理员在租控水电记录页选择园区、账期和房间，系统按相邻抄表记录计算用量和金额。
2. 系统预览异常项，包括缺少起止读数、读数倒挂、单价缺失、房间无有效合同和重复账期。
3. 管理员确认后生成水费、电费合同应收账单；发布后才对企业小程序可见。
4. 企业管理员查看本企业账单并上传付款凭证，账单进入“付款待确认”。
5. 园区管理员在财务所有账单中确认到账，调用现有逐笔收款能力更新累计实收与缴费状态；驳回时填写原因。
6. 企业端展示已缴状态，或根据驳回原因重新上传凭证。

### 小程序接口

- `GET /blade-miniapp/customer/utility-bills`
- `GET /blade-miniapp/customer/utility-bills/{id}`
- `GET /blade-miniapp/customer/utility-bills/{id}/submissions`
- `POST /blade-miniapp/customer/utility-bills/{id}/submissions`

### 后台接口

- 水电账单生成预览、确认生成和发布接口。
- 付款凭证待确认列表、详情、确认到账和驳回接口。
- 生成、发布、确认和驳回操作均要求园区管理员权限并校验授权园区。

## 广告推送设计

### 数据模型

复用 `biz_merchant_ad`，补充：

- `customer_id`、提交成员 ID。
- 审核状态：草稿、待审核、已通过、已驳回。
- 审核人、审核时间和审核意见。
- 现有 `status` 继续表示上架或下架，与审核状态分离。

新增 `biz_merchant_ad_audit_log`，记录广告提交、撤回、审核通过、驳回、上架、下架的广告 ID、动作、前后状态、操作人、操作时间和意见。

### 业务流程

1. 企业管理员在小程序创建广告草稿，填写标题、封面、展示位置、展示时间和跳转内容。
2. 提交后广告进入后台“企业服务—广告管理”的待审核列表，企业端不能直接修改。
3. 园区管理员审核通过或驳回；驳回必须填写原因。
4. 审核通过后可立即上架或按展示时间上架。管理员可随时下架，并记录操作日志。
5. 小程序公共首页仅返回当前园区、审核通过、已上架且处于有效展示期的广告。

### 小程序接口

- `GET /blade-miniapp/customer/ads`
- `GET /blade-miniapp/customer/ads/{id}`
- `POST /blade-miniapp/customer/ads`
- `POST /blade-miniapp/customer/ads/{id}`
- `POST /blade-miniapp/customer/ads/{id}/submit`
- `POST /blade-miniapp/customer/ads/{id}/withdraw`
- `GET /blade-miniapp/customer/ads/{id}/audit-logs`

### 后台接口

扩展现有 `/blade-ics/merchant-ad`：

- 待审核筛选、审核通过和驳回。
- 上架、下架和审核日志查询。
- 审核、上架和下架校验园区范围，并防止非法状态跳转。

## 页面设计

### 小程序首页

快捷区固定四列两行，新增：

- 水电缴纳：登录保护，进入本企业水电账单。
- 广告推送：登录保护；企业管理员进入广告管理，普通成员进入只读列表。

### 水电账单页面

- 列表按待缴、待确认、已缴分类。
- 详情展示房间、表号、账期、起止读数、用量、单价、金额和截止日期。
- 支持上传付款凭证、查看提交记录、查看审核意见和驳回后重新提交。

### 企业广告页面

- 列表展示草稿、待审核、已通过、已驳回、展示中和已下架状态。
- 表单支持标题、封面、位置、展示时间和跳转内容。
- 详情展示审核及上下架时间线。

### 园区后台

- 租控水电记录页增加生成账单、异常预览和确认发布。
- 财务所有账单增加“小程序付款待确认”筛选和凭证审核。
- 广告管理增加审核状态、审核意见和操作记录抽屉。

## 安全与异常处理

- 水电账单必须通过有效合同反查企业、园区和房间，禁止仅凭账单 ID 查询。
- 广告只能由所属企业管理员修改；待审核、已通过和已上架广告禁止直接编辑。
- 凭证和广告提交使用 `X-Request-Id` 与 Redis 幂等控制。
- 水电计费必须拦截读数倒挂、单价缺失、合同失效和重复账期。
- 文件上传沿用现有对象存储，限制图片和 PDF 类型、文件大小并进行访问权限控制。
- 所有返回按钮使用“优先返回上一页、失败回到业务列表”的统一兜底。

## 验收标准

- 首页八个快捷入口排列完整，无空白占位。
- 企业 A 不能查看或提交企业 B 的水电账单、凭证和广告。
- 未发布水电账单不能在企业小程序出现。
- 同一抄表区间不能重复生成有效账单。
- 付款凭证确认后更新现有合同账单实收金额与状态；驳回保留历史记录和原因。
- 企业广告只有审核通过、已上架且在有效期内才显示在首页。
- 广告审核、驳回、上架和下架均可追溯操作人、时间和意见。
- 企业账号无法登录后台，园区管理员后台接口必须校验园区权限。
